모델 (미분방정식)

시뮬 시간 h 스텝 dt h
문법 — name = 값 [min:max] 파라미터(슬라이더 자동 생성, 범위·간격은 [1:12:1] 처럼 지정) · name = 식 계산값(슬라이더 없음) · init X = 식 초기값 · d/dt(X) = 식 미분식 · plot 식 출력. 미분식은 양(X1, X2 …)으로 쓰고, 농도는 C1 = X1/V 처럼 정의해 plot C1 로 그립니다(상태변수에 의존하는 식은 매 시점 자동 계산).
다회투여 — dose X = 용량 every tau for ndoses (또는 ... at 0,12,24). 조건식 t < 2 ? a : b, exp 등 사용 가능. 주석은 ;.
슬라이더 옆 칸에 값을 직접 입력하면 정확히 지정됩니다. 증가 폭을 정하려면 [min:max:step] (예: V = 30 [5:100:5]).
오른쪽 Y축 — plot Xa @right 처럼 곡선을 오른쪽 축에 배치. 축 이름은 그래프 위 입력칸 또는 ylabel/ylabelR 로 지정.
관측 데이터 — 왼쪽 칸에 "시간 농도" 를 붙여넣고 그래프에 표시 를 누르면 점으로 겹쳐져, 슬라이더로 모델 곡선을 맞춰볼 수 있습니다.
